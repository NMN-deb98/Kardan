# کاردان (Kardan)

**کارهایت را هوشمندانه انجام بده**

کاردان یک برنامهٔ اندرویدی فارسی و راست‌چین برای راهنماهای کاربردی، ابزارهای روزمره و مدیریت کارهای شخصی است.

## امکانات نسخهٔ 1.2.0
- دستیار فارسی آفلاین با تأیید پیش از هر اقدام و گزارش صادقانهٔ وضعیت
- مرکز آموزش تصویری: مرحله‌ای، «این روش جواب نداد»، نسخهٔ اندروید، هشدار قدیمی‌بودن، نشان‌دار کردن
- راهنمای کامل بله، ایتا، روبیکا، سروش پلاس، تلگرام و واتس‌اپ
- راهنمای خرید اینترنتی و بستهٔ اینترنت همراه اول، ایرانسل و رایتل (بدون خرید جعلی و بدون ذخیرهٔ اطلاعات کارت)
- فیلم و سریال: فهرست شخصی با جست‌وجوی تحمل‌کنندهٔ غلط تایپی
- برنامه‌ریز با تقویم شمسی، ابزارهای روزمره، گاوصندوق رمز، مدیریت فایل و ابزار PDF

## امکانات نسخهٔ 1.0.3
- رابط کاربری فارسی و راست‌چین با طراحی تیره
- صفحهٔ خانه و دسترسی سریع
- راهنماهای کاربردی همراه با جست‌وجو
- ماشین‌حساب آفلاین با تجزیهٔ عبارت‌های ریاضی
- فهرست کارها با امکان افزودن، انجام‌شده‌کردن و حذف
- ذخیره‌سازی فهرست کارها روی دستگاه
- ساخت خودکار APK و اجرای آزمون‌های واحد با GitHub Actions

## هویت بصری
- نام نمایشی برنامه: کاردان
- نام انگلیسی پروژه: Kardan
- آیکون اختصاصی برای لانچر اندروید و استفاده از همان لوگو در صفحهٔ اصلی برنامه

## نصب
از بخش Releases در GitHub، فایل APK نسخهٔ موردنظر را دانلود و روی دستگاه اندرویدی نصب کنید. ممکن است لازم باشد اجازهٔ نصب برنامه از منبع موردنظر را فعال کنید.

## ساخت از منبع
با JDK 17 و Gradle 8.9 اجرا کنید:

```bash
gradle --no-daemon testDebugUnitTest
gradle --no-daemon assembleDebug
```

فایل خروجی: `app/build/outputs/apk/debug/app-debug.apk`

## محدودیت‌ها
این نسخهٔ اولیه (MVP) است و روی دستگاه فیزیکی و مجموعهٔ گسترده‌ای از نسخه‌های اندروید آزمایش نشده است. قابلیت‌هایی مانند تقویم شمسی، اعلان‌ها و همگام‌سازی ابری در این نسخه ارائه نمی‌شوند.
